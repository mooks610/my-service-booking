## Brand & Style
The design system delivers a clean, modern, and highly legible enterprise corporate SaaS environment engineered for clarity, high data density, and cognitive focus. The visual aesthetic reflects precision, trust, and professional momentum.

The design movement leverages **Corporate Modern** with crisp contrast and structured micro-details:
- **High Readability First**: Strict contrast ratios and bilingual typographic harmony between Korean (Pretendard) and English/numeric accents (Inter).
- **Tactile Enterprise Precision**: Structural clarity over heavy ornamentation. Information architecture is organized through clear borders, subtle tonal shifts, and intentional white space.
- **Dynamic Authority**: Royal Blue `#2563EB` acts as the primary driver for interaction, signaling action, progress, and trust across complex administrative interfaces.

## Colors
The palette is built around high-clarity enterprise fundamentals, utilizing an electric Royal Blue core anchored by soft neutral containers and sharp boundary lines.

- **Primary / Brand Core (`#2563EB`)**: Royal Blue for primary interactive points, active state highlights, focal indicators, and dominant action buttons.
- **Secondary / Container Accent (`#DBEAFE`)**: Soft Blue container used for selected items, hover fills, subtle informational banners, and active tab indicator pills.
- **Surface Lowest / Card Background (`#FFFFFF`)**: Pure white base for cards, tables, modal overlays, dropdowns, and elevated surfaces.
- **Background / Canvas (`#F9FAFB`)**: The neutral page foundation ensuring comfortable contrast against white card surfaces.
- **Border / Outline / Divider (`#E5E7EB`)**: Structural separator defining cards, list rows, form controls, and subtle grid dividers.
- **Primary Text (`#111827`)**: Deep neutral black providing crisp, high-contrast readability across headlines, labels, and running body copy.
- **Secondary Text / Caption (`#6B7280`)**: Balanced slate neutral for muted labels, timestamps, table headers, and supporting metadata.

## Typography
Typographic rhythm is established using **Pretendard** as the foundational base for flawless Korean glyph rendering and general UI prose, paired with **Inter** for English accents, metrics, status badges, and numerical data tables.

- **Headings (Pretendard Bold, 700)**: Deliver punchy visual anchors with negative tracking to eliminate optical spacing drift across multilingual titles. 'SUIT' Bold may serve as an interchangeable display heading alternative.
- **Body (Pretendard Regular, 400)**: Balances density and effortless readability across administrative feeds and enterprise documentation.
- **English Accents & Numerics (Inter Bold/Semibold)**: Used for data readouts, monetary values, timestamps, and compact status badges to leverage Inter's crisp tabular figures and high-legibility x-height.

## Layout & Spacing
The layout follows a fluid 12-column grid optimized for complex enterprise SaaS dashboards, analytics views, and dense resource management tables.

- **Desktop (1024px+)**: 12-column layout with 24px (`gutter-desktop`) gutters and 32px (`margin-desktop`) outer padding. Side navigation bars remain persistent with primary data matrices flexing within the central viewport up to 1440px max width.
- **Tablet (768px – 1023px)**: 8-column layout with 16px gutters and 24px margins. Peripheral panels collapse into flyout panels.
- **Mobile (< 768px)**: 4-column layout with 16px margins. Complex data rows reflow into vertical cards with sticky floating action bars at the screen bottom.

## Elevation & Depth
Visual hierarchy relies on crisp tonal containment paired with low-contrast structural micro-borders, eliminating blurred visual artifacts in favor of clean corporate geometry.

- **Level 0 (Canvas Background)**: Uniform soft tint `#F9FAFB`.
- **Level 1 (Default Containers & Cards)**: Crisp `#FFFFFF` surface bordered by a 1px stroke of `#E5E7EB`. Flat at rest with no drop shadow.
- **Level 2 (Hovered Cards & Interactive Controls)**: Surface remains `#FFFFFF` with a micro ambient lift (`0 2px 4px 0 rgba(0, 0, 0, 0.04), 0 1px 2px 0 rgba(0, 0, 0, 0.02)`) and an active border highlight in `#DBEAFE` or `#2563EB`.
- **Level 3 (Modals, Overlays & Popovers)**: Pure white `#FFFFFF` overlay supported by a clean shadow (`0 10px 15px -3px rgba(0, 0, 0, 0.08), 0 4px 6px -2px rgba(0, 0, 0, 0.03)`) framed against an ambient frosted backdrop (`rgba(17, 24, 39, 0.4)` with `backdrop-blur-sm`).

## Shapes
The design system adopts a **Rounded (`roundedness: 2`)** posture, standardizing interactive components and cards on crisp 8px to 12px radii (`rounded-lg` to `rounded-xl`).

- **Base Controls & Inputs (`0.5rem` / 8px)**: Buttons, text input fields, dropdown trigger targets, and inline filter chips.
- **Containers & Cards (`0.5rem` to `0.75rem` / 8px - 12px)**: Data tables envelopes, analytics widgets, action panels, and calendar surfaces.
- **Modals & Drawers (`0.75rem` / 12px)**: Dialog containers, flyout drawers, and persistent mobile sheets.
- **Status Tags & Badges (`9999px`)**: Full pill geometry reserved specifically for categorical labels, counter badges, and live indicator dots.

## Components

### Buttons
- **Primary**: Background `#2563EB`, text `#FFFFFF`, 8px border radius, font `label-lg` (Inter 600). Hover state deepens to `#1D4ED8`. Active state deepens to `#1E40AF`.
- **Secondary**: Background `#DBEAFE`, text `#1D4ED8`, 8px border radius. Hover state shifts to `#BFDBFE`.
- **Outline**: Background `#FFFFFF`, 1px border `#E5E7EB`, text `#111827`. Hover state applies `#F9FAFB` fill and `#D1D5DB` border.
- **Ghost**: Background transparent, text `#6B7280`. Hover state transitions to `#F3F4F6` with text `#111827`.

### Input Fields & Controls
- Base background `#FFFFFF`, border 1px `#E5E7EB`, border radius 8px (`0.5rem`), padding `0.5rem 0.75rem`, text `#111827`, placeholder `#9CA3AF`.
- **Focus**: Border shifts to `#2563EB` with a 3px outer focus ring in `rgba(37, 99, 235, 0.15)`.
- **Error State**: Border `#EF4444` with focus ring in `rgba(239, 68, 68, 0.15)`.

### Cards & Data Panels
- Background `#FFFFFF`, 1px outline `#E5E7EB`, corner radius 12px (`rounded-xl`).
- Clear visual hierarchy with a 16px padded header zone, muted divider stroke `#E5E7EB`, and structured body.

### Chips & Badges
- **Status Badges**: Pill-shaped (`rounded-full`), padding `2px 8px`, typography `label-sm`.
  - *Active / Success*: Background `#DCFCE7`, text `#15803D`.
  - *Info / In-Progress*: Background `#DBEAFE`, text `#1D4ED8`.
  - *Neutral / Inactive*: Background `#F3F4F6`, text `#4B5563`.
- **Filter Chips**: Height 32px, 8px corner radius, `#FFFFFF` surface with `#E5E7EB` border. Selected state uses `#DBEAFE` background with `#2563EB` text and border.

### Checkboxes & Radio Buttons
- 16px dimension, 4px border radius for checkboxes and circular for radios.
- Unchecked: `#FFFFFF` fill with 1px `#D1D5DB` border.
- Checked: `#2563EB` fill with white checkmark icon or center dot. Focus ring matches input style.

### Data Tables & Lists
- Table headers utilize `#F9FAFB` fill, typography `label-md` uppercase in `#6B7280`, and bottom border `#E5E7EB`.
- Row cells utilize `#FFFFFF` background, 14px body text (`#111827`), tabular numerals for numerical metrics, and 1px border separator `#E5E7EB`. Hover state applies `#F9FAFB`.
